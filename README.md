# AJBell-equity-research-project
A full DCF Model and investment memo for AJ Bell PLC (AJBL), a UK listed investment platform. Built from first principles using FY22-25 audited financials and H1 FY26 interim results. I use a bottom up revenue build from AUA growth and fee margin assumptions, NOPAT to UCF bridge, WACC via CAPM and obtain terminal values using both Gordon Growth and EV/EBITDA exit multiples. I find that the DCF implies a fair value of 696p representing a 14.7% upside when compared to the current market price of 607p (as of 10th July 2026). I also conduct a sensitivity analysis ontop of including a comparable company analysis. My results and recommendations are summarised in a one page investment memo
